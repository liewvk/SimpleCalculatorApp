# Simple Calculator App

A C# application for performing basic calculator operations.

## Description

This project provides a simple calculator application with a user-friendly interface for performing mathematical calculations.

## Technology Stack

- **Language**: C#
- **.NET Framework**: .NET

## Getting Started

### Prerequisites

- .NET SDK
- Visual Studio or Visual Studio Code (recommended)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/liewvk/SimpleCalculatorApp.git
   ```

2. Navigate to the project directory
   ```bash
   cd SimpleCalculatorApp
   ```

3. Build the project
   ```bash
   dotnet build
   ```

### Usage

Run the application:
```bash
dotnet run
```

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Simple and intuitive user interface
- Real-time calculations
- Error handling for invalid inputs
